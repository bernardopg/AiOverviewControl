# 1.18.0: telemetry, currency, dashboard and release safety

This is a feature release, not a change to provider billing or credential formats.
Version authority remains `plugin.json`. The exact published release body comes
from the matching section in `CHANGELOG.md`.

## User-visible changes

- **Estimated cost currency:** Settings supports USD, EUR, BRL, GBP, CAD, CNY,
  JPY, AUD and CHF. USD remains the default. Analytics estimates use the latest
  daily reference quote; missing quotes explicitly display USD. Provider-native
  balances, credits, history and exports keep their original units. See
  [currency](../currency.md) for precision, stale-cache notices and privacy.
- **Pinned provider ordering:** drag the ↕ handle directly onto another pinned
  card. No hold is needed, and the gesture no longer scrolls the page. The header
  aligns the handle, larger logo, percentage, navigation/actions and collapsed
  accent stripe. The star button enables pinning; order persists automatically.
- **Quota and credit accuracy:** Codex windows are labeled from their actual
  durations; zero credit balances remain valid. Credit history/export includes
  `credit_balance`; credit-only samples do not fabricate percentage sparklines.
- **Kimi:** Code subscription quotas and Open Platform balances remain separate.
  Detailed five-hour/long-window limits take precedence over conflicting ratio
  pools. The official Code API stays on `api.kimi.com`; credentials are not
  forwarded to alternate domains. See [Kimi research](../kimi-domains-research.md).
- **History feedback:** retention writes are locked/atomic, malformed lines are
  tolerated, and Settings reports snapshot count and last trimming feedback.
- **Localization:** selectable provider descriptions and duration-based quota
  labels are covered in English, Brazilian Portuguese, German, Spanish and
  Simplified Chinese. The five locale bundles have 318 matching keys.

## Runtime and maintenance

Dashboard/hero/manager/cards moved into `DashboardContent.qml`; the widget retains
state, orchestration and bar pills. Five analytics readers share
`LocalAnalyticsReader.qml`. 9Router/Pi/Hermes retain successful snapshots on
transient transport/parse/timeout failure, but clear valid error responses.
Currency formatting has its own module, with safe in-flight setting changes.

The dispatcher explicitly sources 33 native fetch functions from 31
`providers/native/*.bash` modules. Their provider-facing output contracts are
unchanged. These are source modules, not executable entrypoints. See
[refactoring](../refactoring.md) and [architecture](../architecture.md).

QML components load by URL for reliable hot reload. `scripts/reload-plugin`
discovers the actual DMS instance instead of assuming a config path. Empty-provider
bindings and the settings dropdown/window loading interfaces are corrected.

## Upgrade and privacy

No manual storage migration is required. Existing settings retain USD unless the
user changes `costCurrency`; reset-to-defaults restores USD. Rates use a private
atomic cache, fresh for 24 hours, with a maximum seven-day stale fallback.
`AIOC_NO_FX=1` disables rate requests. Frankfurter receives only currency codes,
not provider keys, accounts or spend. Historical displays use the latest quote,
not the historical transaction's settlement rate.

Provider credentials keep their existing locations. No host-package inventory
belongs to this release's dependency audit: [update audit](../update-audit.md)
covers repository-managed GitHub Actions and pinned CLI artifacts only.

## Release protections and validation

PRs must pass `Changelog integrity` and the complete required CI job set. A PR
without a version bump must add a substantive `Unreleased` bullet. A version bump
must advance the version and have a unique, nonempty matching release section.
Heading/comment/placeholder-only bodies fail. Packaging checks the archived notes,
not only the working copy, and publication uses the same exact section extractor.

See [repository rules](../repository-rules.md) for main/tag rulesets and their
operational limits, and [release checklist](../release-checklist.md) for the PR,
merge, main CI, immutable tag and checksum-verification sequence.

Fixture suites cover provider contracts, cache/opt-out/concurrency, history,
locale parity, metadata rejection, workflow tooling and changelog failures.
Offscreen Quickshell covers reader/currency lifecycle. Real-DMS runtime checks
exercise the widget, settings/window, focus and currency bindings. The optional
`AIOC_TEST_POINTER=1 tests/test-widget-runtime.sh` opens an isolated fixture window
and checks fast pointer drag, unchanged scroll position and header geometry.
Generic CI still needs native Wayland/DMS imports for that full UI exercise;
SKIP is not claimed as native pointer coverage. External billing APIs without
available endpoints and untested touch/monitor configurations remain limitations.
