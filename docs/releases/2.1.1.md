# 2.1.1: DankDash card translations

This patch release for DMS 2.0 translates the DankDash card's name and options
into Portuguese, Spanish, German and Chinese. In 2.1.0 they stayed English in
every language, while the text inside the card was already translated.
Settings, Claude profiles, pins and history carry over unchanged. Version
authority remains `plugin.json`; the published release body comes from the
matching section in `CHANGELOG.md`.

## Upgrading

- Requires DMS 2.0 or newer, as 2.1.0 does. DMS 1.6 users stay on
  [1.22.0](https://github.com/bernardopg/AiOverviewControl/releases/tag/v1.22.0).
- Run `dms restart` once after upgrading. DMS reads the plugin manifest and its
  `translations/` directory only on start-up or when its language changes, so
  a plain plugin reload keeps the English strings.
- Coming from 2.0.x without having restarted since: the restart is also what
  makes the **AI quotas** card appear in **Add widget**, because 2.1.0 turned
  the manifest into a composite plugin.

## User-visible changes

- **Translated DankDash card**
  ([#77](https://github.com/bernardopg/AiOverviewControl/pull/77)): the card
  name in **Add widget** and its edit-mode options now follow the DMS language.
  In Portuguese, for example, they read **Cotas de IA**, **Provedores**
  (**Ajustar ao tamanho**, 1, 3, 6) and **Tom** (**Superfície**, **Primário**,
  **Secundário**, **Terciário**). The tone choices reuse the terms DMS already
  uses, so they match the rest of the shell. See
  [The DankDash card](../usage.md#the-dankdash-card).
- DMS draws these strings itself, so they follow **Settings → Locale** in DMS,
  not the plugin's **Language** setting. Everything inside the card and the
  popout still follows the plugin setting.

## Maintenance

- New `translations/pt.json`, `es.json`, `de.json` and `zh.json` in the DMS
  plugin-translation format, looked up through `I18n.trFor`. Short language
  tags cover every regional variant, like the plugin's own locale matching.
- `translations/` is required in the release archive and in the documented
  checkout install command; `scripts/check-metadata` guards the latter.

## Validation

- `tests/test-i18n.sh` now fails when a `plugin.json` dash string is missing,
  empty or left in English in any locale, or when a plugin language has no
  `translations/` file. Removing one term from `translations/de.json` makes it
  fail, as intended.
- The metadata, changelog and badge gates pass, and all 20 checks passed on
  [#77](https://github.com/bernardopg/AiOverviewControl/pull/77).
- Verified live on DMS 2.0 in Portuguese: after `dms restart`, **Add widget**
  lists the card as **Cotas de IA** and the card adds and renders.

## Limitations

- Languages beyond the plugin's five fall back to the DMS catalog and then to
  English for the card name and options, as they do inside the plugin.
