# 2.6.0: QwenCloud, Claude accuracy fixes, Antigravity repairs

This minor release for Dux Shell 2.0 and 2.1 adds **QwenCloud** as a new provider for Alibaba's international Qwen storefront, fixes Claude local analytics double-counting and zeroed daily bars, and repairs Antigravity cloud quota detection for the Gemini Models pool and ACP token sessions.

Settings, Claude profiles, pins and history carry over unchanged. Version authority remains `plugin.json`; the published release body comes from the matching section in `CHANGELOG.md`.

## Upgrading

- Requires Dux Shell 2.0 or newer; 2.1 is tested. DMS 1.6 users stay on [1.22.0](https://github.com/bernardopg/AiOverviewControl/releases/tag/v1.22.0).
- `dms restart` is recommended after updating so the bar, dashboard, and settings pick up the new provider and QML fixes.
- QwenCloud is not added automatically. Install the QwenCloud CLI (`npm i -g @qwencloud/qwencloud-cli`), sign in with `qwencloud auth login` (read-only `usage:read` scope), and enable the provider in settings or through **Detect providers**.
- Existing Claude transcript caches rebuild on the next refresh because the transcript cache header bumped to `v2` to clear inflated dedup data.

## QwenCloud provider

New `qwencloud` provider (alias `qwen-cloud`) for [home.qwencloud.com](https://home.qwencloud.com/), Alibaba's international Qwen storefront. It is separate from the DashScope `qwen` card: different console, API keys, and billing ([#134](https://github.com/bernardopg/AiOverviewControl/pull/134), thanks [@gtheys](https://github.com/gtheys)).

- Reads data through the official QwenCloud CLI using read-only account commands.
- Shows the **Token Plan** monthly Credits bar with reset date when subscribed.
- Shows this month's pay-as-you-go spend and the count of valid free-tier model quotas.
- Without a Token Plan, the free tier or PAYG spend leads the card.
- Missing CLI or expired login produce actionable errors.
- Covered by `tests/test-qwencloud.sh`.

## Claude fixes

- **Transcript dedup (#131, [#135](https://github.com/bernardopg/AiOverviewControl/pull/135)):** Claude Code writes one JSONL line per content block and repeats the full `message.usage` object on each line. The local analytics extractor now deduplicates assistant rows by `message.id` (first occurrence wins), appends `message.id` to the cached TSV row, and bumps the transcript cache header to `v2` so inflated caches rebuild. Id-less assistant rows pass through defensively. Covered by `tests/test-claude-dedup.sh`.
- **Daily bars / Today tokens (#130, [#136](https://github.com/bernardopg/AiOverviewControl/pull/136)):** `ClaudeProfiles.week()` now accepts array-like QML `QVariantList` wrappers, preventing daily token/cost bars and Today tokens from rendering as zero when analytics data was present. Covered by `tests/test-qml-smoke.sh`.

## Antigravity fixes

- **Gemini Models cloud pool (#133, [#137](https://github.com/bernardopg/AiOverviewControl/pull/137)):** Cloud quota requests now default to `ANTIGRAVITY_CLIENT_VERSION=2.6.0` and send the same version in User-Agent and `X-Client-Version`, restoring Gemini Models 5h/Weekly pools gated by newer client versions. The value remains configurable via `ANTIGRAVITY_CLIENT_VERSION`.
- **ACP token discovery (#132, [#138](https://github.com/bernardopg/AiOverviewControl/pull/138)):** The native adapter and provider health check now discover `~/.gemini/antigravity-acp/acp_token.json` and accept top-level/nested refresh token shapes. Covered by `tests/test-antigravity-live.sh`.
